Quick Guide

1. PLAN

⚙ ตั้งค่า → ใส่รายรับ เงินออม ค่าใช้จ่ายประจำ และค่าใช้จ่ายรายปี

2. ACTUAL

กด + เพื่อบันทึกรายรับ/รายจ่ายที่เกิดขึ้นจริง วันที่เป็น dd/mm/yyyy เช่น 04/09/2026

3. HISTORY

ดูแท็บประวัติ กรองรายเดือน และตรวจว่าบันทึกซ้ำหรือไม่

4. POSITION

เพิ่มเงินสด เงินฝาก หุ้น กองทุน สลาก เงินเกษียณ ทอง อสังหาริมทรัพย์ และหนี้

5. BACKUP

ข้อมูลอยู่ใน Browser เครื่องนี้ ควร Backup JSON เป็นระยะ โดยเฉพาะบน iPhone
