# Moji Android Test App

This branch contains the Android test shell for Moji.

- App name: Moji
- Test package: `com.tnlxacc.moji`
- Target SDK: Android 16 / API 36
- Web app source: https://tnlxacc-sketch.github.io/smart-personal-finance/
- The Android app keeps its own WebView storage and does not change the live website.

The first goal is a debug APK for installation testing before preparing the Play Store AAB.
