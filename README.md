# Smart Personal Finance Manager

เครื่องมือบริหารการเงินส่วนตัวแบบ Local-first

- ไม่มีฐานข้อมูลและไม่มี Login
- ข้อมูลการเงินเก็บใน Browser ของผู้ใช้แต่ละเครื่องผ่าน Local Storage
- GitHub Pages ใช้โฮสต์เฉพาะตัวโปรแกรม ไม่ได้เก็บข้อมูลการเงินของผู้ใช้
- รองรับ iPhone ผ่าน Safari และ Add to Home Screen
- มี Quick Guide, Plan/Budget, Actual Income/Expense, History, Duplicate Warning, Assets, Debts, Net Worth, Emergency Fund และ Backup JSON

วันที่รายการจริงแสดงเป็น `dd/mm/yyyy` เช่น `04/09/2026`
